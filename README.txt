# Taplógáz – F1 honlap

GitHub Pages-kompatibilis statikus weboldal.

## Feltöltés GitHubra
1. Hozz létre egy új repositoryt GitHubon.
2. Töltsd fel az `index.html`, `cikk.html`, `style.css` és `script.js` fájlokat.
3. A repositoryban menj a **Settings → Pages** részhez.
4. A **Build and deployment** alatt válaszd: **Deploy from a branch**.
5. Branch: `main`, mappa: `/ (root)`, majd Save.
6. Pár perc múlva megjelenik a honlap címe.

A `cikk.html` jelenleg mintaanyag; később az aktuális F1-hírekhez készíthetünk új cikkoldalakat.
